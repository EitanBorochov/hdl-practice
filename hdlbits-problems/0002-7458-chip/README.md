# HDLBits: 7458 Chip

Problem: [7458](https://hdlbits.01xz.net/wiki/7458)

Goal: Create a module with the same functionality as the 7458 chip. It has 10 inputs and 2 outputs. You may choose to use an assign statement to drive each of the output wires, or you may choose to declare (four) wires for use as intermediate signals, where each internal wire is driven by the output of one of the AND gates. For extra practice, try it both ways.

## Run locally

```sh
make test
make wave
```

## What I learned

- Applied gate logic basics.
- Main part of the learning was learning how to create a proper and extensive testbench.
