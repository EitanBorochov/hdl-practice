# HDLBits: Vector0

Problem: [Vector0](https://hdlbits.01xz.net/wiki/Vector0)

Goal: Build a circuit that has one 3-bit input, then outputs the same vector, and also splits it into three separate 1-bit outputs. Connect output o0 to the input vector's position 0, o1 to position 1, etc.



## Run locally

```sh
make test
make wave
```
