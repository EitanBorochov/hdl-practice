# HDLBits: Wire4

Problem: [Wire4](https://hdlbits.01xz.net/wiki/Wire4)

Goal: Create a module with 3 inputs and 4 outputs that behaves like wires that makes these connections:
a -> w
b -> x
b -> y
c -> z

## Run locally

```sh
make test
make wave
```

## What I learned

- Did this one to practice making a test bench from scratch. I want it to be muscle memory for me.
- Practiced creating random tests using a for loop and urandom.
